## 🧠 whoami

I design **AI-powered backends** and **cloud-native systems**, mostly in Python and across Azure / AWS / GCP.
Lately, I spend more time wiring **LLMs and agents** into real production workflows than writing plain CRUD.

- 🔭 **Now:** building agentic pipelines that reason over enterprise data
- 🌱 **Learning:** evals, prompt-cache economics, observability for LLM apps
- 🤝 **Open to:** collabs on AI + automation projects
